## 🦀 Sobre Rust

Rust é uma linguagem de programação moderna focada em **performance, segurança e concorrência**, oferecendo controle de baixo nível semelhante a linguagens como C e C++, mas utilizando um sistema de tipos e regras de compilação capazes de prevenir diversas categorias de erros relacionados à memória.

Um dos principais conceitos da linguagem é o sistema de **Ownership**, que permite gerenciamento seguro de memória sem depender de um Garbage Collector.

Rust é utilizada em áreas como:

* Programação de sistemas
* Ferramentas de linha de comando
* Back-end
* Sistemas embarcados
* WebAssembly
* Infraestrutura
* Redes
* Sistemas distribuídos
* Aplicações de alta performance
